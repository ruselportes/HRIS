02 — Home rules

The sync bar is structural
Pinned under the header on every screen, never dismissible, always carrying a count when there is one. Green synced, grey offline with elapsed time, orange while uploading.
One button owns the screen
Take Attendance is 96px and the only filled element. Its sub-label changes with progress — “7 workers still to mark”, “Start with all 38”.
Delegated actions stay visible
Report Absent Foreman is greyed with its condition stated when not delegated, and gains an amber rule naming the covered crew when it is. A foreman should learn it exists before he needs it.
Roll call breaks down by status
Present, late and absent counts sit under the progress bar, so the foreman can answer the engineer's radio question without opening the list.
