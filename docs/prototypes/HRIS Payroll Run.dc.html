The multiplier is on the line
×1.25 next to the hours and the peso rate it produced. A worker can check his own payslip without a calculator or an explanation.
Night differential is a premium
It pays 10% on hours already counted elsewhere, so the line shows ₱12.25/hr, not ₱134.75. Stating it prevents the most common double-count dispute.
Premium hours are columns
OT, ND, rest day and holiday sit in the register itself, so an unusual row is visible while scanning rather than only inside a payslip.
Unresolved attendance blocks pay
A row whose hours are still in recovery is computed but cannot be released. The block links straight to the sign-off case.
