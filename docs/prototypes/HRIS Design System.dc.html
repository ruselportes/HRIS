06 — Rules of the system

Colour is never the only signal
Every status carries a dot shape, glyph or word. Screens are read in direct sunlight through scratched glass.
Offline is a state, not an error
Grey and orange, never red. Red is reserved for a record that was rejected or a worker who was absent.
One primary per view
The solid accent button is the only filled object on a screen. Everything else is a line drawing.
Audited actions say so
Overrides, approvals and payroll edits name the consequence and the log before the confirm button.
