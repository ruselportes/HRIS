A crew with no foreman is an error
Red rule on the crew, red badge on the site header, and a count in the summary. Nobody can start a shift unsupervised without it being visible from the top of the screen.
Drag is a shortcut, not the only path
Checkboxes plus an Assign arrow do the same job. The same screen works on a tablet in a site office where drag is unreliable.
Certification blocks assignment
Expired certs and approved leave grey a worker out in the pool. HR's compliance data becomes an operational guardrail here.
