02 — Queue rules

The signature is a mark, not a message
A small green lock beside each name means the record is signed by this phone. Tapping it explains; nothing else on screen mentions it.
Sync Now is reassurance
Uploading is automatic. The button exists so a worried foreman has something to press — and it stays disabled with a reason when there is no signal.
A failure names the person
Not a code. The reason is stated in HR's terms — “HR has him on approved leave today” — with two plain choices and no free typing.
Last successful sync always shows
In every state, including offline. It is the single fact that tells a foreman how much is at stake if the phone breaks.
